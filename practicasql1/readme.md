## Se utiliza node.js
 - Se debe instalar node.js (según el sistema operativo, puede ser un poquito diferente)
 - En el subdirectorio de backend, se debe ejecutar en la terminal los siguientes comandos:
    - npm init -y
    - npm install express pg dotenv cors
 - Se crean los archivos en backend/
   - .env
   - server.js
